# React / Ant Design 界面重构验收

后续的界面细化、全量 API 回归和独立浏览器端到端测试已补充完成，最新结果见 [前台 API 集成与端到端验收](./前台API集成与端到端验收.md)。以下保留初轮改造记录，其中浏览器工具限制已由仓库内自动化测试补齐。

入口：`/app`。本地开发服务：`http://127.0.0.1:18084/app`。未发布生产。

## 已实现

- React 19、TypeScript、Ant Design 6、Vite 6 的前端构建与 FastAPI 静态服务接入。
- 登录、侧栏导航、业务概况、指标卡、响应式布局、统一反馈与错误提示。
- 企业／联系人双视图表格、服务端搜索和分页、列显示、当前页批量选择、保存筛选视图。
- 客户详情抽屉、企业证据、疑似关联提示、联系人及独立验证状态、跟进与验证历史。
- 企业评审、联系记录、批量跟进的 Ant Design 表单弹窗；保留相关幂等键和外部验证确认。
- 任务表格、类型与状态筛选、已有任务轮询及详情入口。
- 前端资源内容版本、每次响应的样式 nonce、初始化失败保护、账号清理时清除上一账号点数。
- 旧表单样式隔离，旧入口 `/app?legacy=true` 可回退。

找客引导、企业资料、客户编辑、导入、收件归档、邮件审阅、费用与任务详情继续通过兼容层使用原业务表单；本次没有将这些表单全部改写为 React。
