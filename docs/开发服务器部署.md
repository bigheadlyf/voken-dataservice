# 开发服务器部署

部署服务器：`8.163.73.136`，SSH 端口 `22`。

- 客户工作台：http://8.163.73.136/api/app
- 测试台：http://8.163.73.136/api/
- 接口文档：http://8.163.73.136/api/docs
- 健康检查：http://8.163.73.136/api/health
- 业务接口：`/api/v1/...`，保持原有路径。

Nginx 反向代理 `/api/` 下的请求，不剥离路径前缀。`/api` 自动跳转至 `/api/`；根路径 `/` 保留现有官网静态站点，本轮未修改官网或 Nginx 配置。客户工作台入口为 `/api/app`。
服务器应用配置设置 `WEB_PREFIX=/api`，用于测试台、静态资源、健康检查和 OpenAPI 文档路径；本地默认空值，仍可从根路径访问。

## 运行环境

Alibaba Cloud Linux 4，Python 3.11，MySQL 8.4.13，Nginx。
应用使用 `APP_ENV=test`，注册验证码为 `123456`。这是开发测试环境。
数据库 `voken` 当前迁移至 `0015`。本轮从 `0006` 升级，先在临时 MySQL 副本校验迁移，确认旧记录数量不变后才升级测试库；保留现有账号与业务数据，没有导入本地开发数据。
本地开发模型使用 `deepseek-flash`（`https://api.deepseek.com`）；线上测试服务器模型使用 `qwen4-max`（`https://maas-api.simple-server.cn/v1`），通过各自环境变量配置。search/fetch 地址在代码中固定为 `https://api.deepseek.com`，不随 `LLM_BASE_URL` 或其他环境变量变化；各环境必须单独配置 `TOOLS_API_KEY` 为 DeepSeek 密钥，不回退使用模型密钥。海关接口保持原配置。密钥仅保存在各环境私有配置文件中。

应用以 `voken` 系统用户、单 worker 运行，通过 Nginx 的 80 端口访问。
应用监听 `127.0.0.1:18000`，MySQL 监听 `127.0.0.1:3306`。
三个服务均配置了开机自启，应用异常退出自动重启。

- 应用版本：`/opt/voken-dataservice/releases/`
- 当前版本链接：`/opt/voken-dataservice/current`
- 当前 Python 环境：`/opt/voken-dataservice/venvs/20261122-react-api-f4fa19d`；旧共享环境 `/opt/voken-dataservice/venv` 保留供回退
- 实际依赖版本：`/opt/voken-dataservice/deployed-requirements.txt`
- 应用配置：`/etc/voken-dataservice/app.env`，权限 `root:voken 640`
- 数据库管理员配置：`/root/.my.cnf`，权限 `600`
- 数据库监听配置：`/etc/my.cnf.d/voken.cnf`，由 `/etc/my.cnf` 引入
- 应用服务：`/etc/systemd/system/voken-dataservice.service`
- Nginx 配置：`/etc/nginx/conf.d/voken-dataservice.conf`

密码与 API 密钥不记录在本文中。

```bash
systemctl status voken-dataservice nginx mysqld
journalctl -u voken-dataservice -n 100 --no-pager
systemctl restart voken-dataservice
curl -fsS http://127.0.0.1:18000/api/health
mysql -e 'SELECT version_num FROM voken.alembic_version;'
```

修改应用配置后，运行 `systemctl restart voken-dataservice`。
修改 Nginx 配置后，运行 `nginx -t && systemctl reload nginx`。

如需从本地连接数据库，可使用 SSH 隧道：

```bash
ssh -L 13307:127.0.0.1:3306 root@8.163.73.136
```

数据库应用账号为 `voken`，密码在服务器应用配置的 `DATABASE_URL` 中。

### 规范打包

Windows 上必须禁用 Git 的工作区换行转换进行归档，使服务器文件字节与提交一致：

```powershell
git -c core.autocrlf=false archive --format=tar.gz --output=.local/release.tar.gz HEAD
```

部署包不包含 `.env`、`.local`、SSH 私钥、数据库文件、`node_modules` 或其他被忽略的运行数据。前端已构建，服务器无需安装 Node。

只读页面验证脚本：`node tests/deployed_ui_smoke.cjs http://8.163.73.136/api/app`。若本机浏览器阻断该目标，应报告限制，不能把未运行的浏览器检查记为成功。

### 回退

本轮升级前版本为 `/opt/voken-dataservice/releases/20261120-042033-qwen-output-fix`。回退时停止应用，恢复备份的 `app.env.before-activate`，移除本轮新增的 `release.conf`，将 `current` 指回旧版本，执行 `systemctl daemon-reload` 并启动应用。旧共享虚拟环境仍保留。

迁移均为新增结构；回退代码时保留新增表和现有数据，不执行删除表的 downgrade，不直接覆盖数据库备份，以免丢失发布后新记录。
